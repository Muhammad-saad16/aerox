# aerox

Portfolio website for **Aerox ERP** (aerospace, robotics & AI) and its founder **Aiman Fatima**.

- `index.html`: Aerox ERP company site
- `aiman.html`: "Who's Aiman" founder page
- `css/aerox.css`, `js/main.js`: styles and behaviour for the redesigned `index.html`
- `css/style.css`, `js/art.js`: styles and visuals still used by `aiman.html`
- `images/`: logo, project photos and founder photos

Static site: open `index.html` in a browser, or deploy the folder to any static host.
